# AI Job Replacement Analysis

## Project Objective
This project analyzes the impact of AI adoption on automation risk, salary changes, workforce adaptability, and reskilling requirements.

## Tools Used
- Python
- Pandas
- NumPy
- Seaborn
- Matplotlib

## Key Insights
- Higher AI adoption increases automation exposure in repetitive roles.
- Skill gaps strongly influence reskilling urgency.
- Salary-related variables show strong relationships after AI adoption.
- Experience alone does not protect employees from automation.

## Visualizations
- Countplots
- Boxplots
- Heatmaps
- Pairplots
- Correlation Analysis

## Conclusion
AI is transforming workforce dynamics by increasing automation risk in repetitive roles while rewarding adaptable and technology-oriented employees.
